Personal Google Drive client

rclone

This personal OAuth client allows its owner, prok20, to connect the rclone command-line tool to their own Google Drive account.

Purpose

The client is used for personal file transfers, synchronization, and backups between Google Drive and devices or storage destinations configured by the owner. It is intended for the owner's personal use.

Google Drive access

Google authorization lets rclone perform the file operations allowed by the permissions granted during sign-in. Depending on the selected permissions and commands, these may include listing, reading, downloading, uploading, updating, or deleting Drive files.

This website only provides information about the client. Google sign-in and file operations take place through rclone; this website does not receive OAuth tokens or Drive files.

Read the privacy policy for details about data handling and how to revoke access.
